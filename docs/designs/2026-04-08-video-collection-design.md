# 短视频收藏 + AI 分类 + 要点提取

> 日期：2026-04-08 | 状态：已批准

## 概述

在 MemoryEverything 现有链接收藏体系上扩展，支持微信视频号短视频的收藏、自动分类和要点提取。采用"数据层复用 + 视频专属视图"方案（方案 C）。

## 需求摘要

| 维度 | 决策 |
|------|------|
| 视频来源 | 微信视频号 |
| 保存方式 | 微信分享到小程序 + 剪贴板检测，两种都支持 |
| 自动分类 | AI 自动归类 + 用户可手动调整/新建分类 |
| 要点提取 | 一句话摘要 + 详细要点列表 |
| AI 信息来源 | MVP 基于标题+描述文字，后续逐步加截图分析和语音转文字 |
| 优先级 | 优先开发，不等后端迁移 |

## 数据层设计

在现有 `links` 表上扩展三个字段，不新建表：

| 字段 | 类型 | 说明 |
|------|------|------|
| `video_author` | TEXT | 视频号作者名 |
| `video_duration` | INTEGER | 视频时长（秒） |
| `key_points` | JSON | AI 提取的要点 |

通过 `source = 'wechat_video'` 区分视频和普通链接。

### key_points 结构

```json
{
  "summary": "一句话摘要：教你3分钟做出完美溏心蛋",
  "points": [
    "水开后放入鸡蛋，计时6分30秒",
    "捞出后立即放入冰水降温",
    "剥壳时从气室端开始"
  ],
  "extracted_at": "2026-04-08T10:00:00Z"
}
```

分类和标签复用现有 `category` 和 `tags` 字段。

## 后端 API 设计

### 视频号链接解析增强

现有 `POST /links/parse` 增强：

- 解析视频号页面，提取 `video_author`、`video_duration`（从页面 meta 信息抓取）
- 抓不到时降级：只保存标题+描述，作者/时长留空

### 新增路由：AI 要点提取

`POST /ai/extract-points`

```
请求：{ linkId: "xxx" }
响应：{ summary: "一句话摘要", points: ["要点1", "要点2", ...] }
```

流程：
1. 根据 linkId 取出链接的 title + description + category
2. 拼装 prompt 发给 AI（通义千问），要求返回一句话摘要 + 详细要点
3. 结果写入 `links` 表的 `key_points` 字段
4. AI 不可用时降级：摘要=description 截取前50字，要点=空数组

### AI 分类 prompt 优化

针对视频类内容：
- prompt 中加上"这是一条视频号短视频"上下文
- 分类候选增加：教程、生活记录、知识科普、搞笑、种草

### 保存时自动触发

`POST /links` 保存时，如果 `source === 'wechat_video'`，异步触发 AI 分类 + 要点提取（不阻塞保存响应）。

## 视觉风格

深色模式为主，Material Dark 风格。

| 元素 | 色值 | 说明 |
|------|------|------|
| 背景色 | #121212 | 页面底色，深灰 |
| 卡片背景 | #1E1E1E | 卡片/容器背景 |
| 主文字 | #E0E0E0 | 标题、正文 |
| 次级文字 | #9E9E9E | 时间、作者、描述 |
| 强调色 | #BB86FC | 按钮、标签、高亮要点、Tab 选中态 |
| 强调色（按下态） | #9A67EA | 按钮按下反馈 |
| 分割线 | #2C2C2C | 列表分割、卡片边框 |
| 危险操作 | #CF6679 | 删除按钮等 |

全局圆角 8px，卡片间距 12px，视频缩略图圆角 6px。

## 小程序前端设计

### 入口

**入口1 — 微信分享：** 视频号点「分享到小程序」，小程序 `onShow` 接收分享参数，跳转添加确认页。

**入口2 — 剪贴板检测：** 复用现有逻辑，增加视频号链接域名识别（`channels.weixin.qq.com`、`finder.video.qq.com` 等），检测到后弹窗询问是否保存。

### 首页 tab 切换

在现有首页 index 顶部加 tab 切换：「全部 | 链接 | 视频」，不新增 TabBar 项。

### 视频列表页（pages/video-list/video-list）

- 顶部：分类筛选栏（全部 / AI 自动分类标签）
- 卡片样式：
  - 左侧：视频缩略图（带播放图标叠加）
  - 右侧：标题、作者、时长、分类标签
  - 底部：一句话摘要（key_points.summary）
- 搜索：复用现有搜索，筛选 `source=wechat_video`
- 空状态：引导文案"还没收藏视频，去视频号分享试试"

### 视频详情页（pages/video-detail/video-detail）

- 顶部区域：缩略图（可点击跳转原视频）、标题、作者、时长
- 要点卡片（核心区域）：
  - 一句话摘要，加粗
  - 详细要点列表，带序号
  - 右上角「重新提取」按钮
  - 未提取时显示「提取要点」按钮
- 分类 & 标签：显示当前分类，点击可修改
- 用户点评区：复用现有点评组件（评分 + 文字）
- 底部操作栏：「打开原视频」「删除」

## 降级策略

| 环节 | 正常 | 降级 |
|------|------|------|
| 视频号解析 | 抓取标题/描述/作者/时长/缩略图 | 仅保存 URL，其余留空 |
| AI 分类 | 自动归类 + 标签 | 分类为"未分类"，用户手动选 |
| AI 要点提取 | 一句话摘要 + 要点列表 | 摘要=description 前50字，要点=空 |
